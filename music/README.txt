ПАПКА ДЛЯ МУЗЫКИ

Сюда клади музыкальные файлы для проекта.
Поддерживаемые браузером форматы обычно: .mp3, .ogg, .wav, .m4a.

ВАЖНО: просто добавить файл сюда недостаточно — чтобы трек появился в меню «Выбор музыки», его нужно также добавить в список MUSIC_TRACKS в index.html.
Пример записи:
{name: 'Название трека', src: './music/название-файла.mp3'},

Имя файла и путь должны совпадать точно, включая большие/маленькие буквы (на GitHub Pages это важно).
