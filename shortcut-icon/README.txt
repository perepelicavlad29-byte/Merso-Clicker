ЗНАЧОК ЯРЛЫКА ИГРЫ

Файл game-icon.ico — значок для ярлыка Windows.
Файл game-icon.png — исходная картинка, которую можно заменить своей.

Как поставить значок на ярлык:
1. Создай ярлык для index.html (правый клик по index.html -> Показать дополнительные параметры -> Создать ярлык, если доступно).
2. Нажми правой кнопкой по ярлыку -> Свойства -> Веб-документ или Ярлык -> Сменить значок.
3. Нажми Обзор и выбери shortcut-icon\game-icon.ico.
4. Нажми ОК -> Применить.

Если заменяешь картинку, Windows для ярлыка использует именно .ico. PNG сам по себе в окне выбора значка может не подойти; после замены PNG нужно преобразовать его в ICO.
